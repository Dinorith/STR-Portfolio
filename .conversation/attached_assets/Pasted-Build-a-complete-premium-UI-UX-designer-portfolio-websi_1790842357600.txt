- Hard rectangular shapes
- Thick borders
- Black outlines
- Hard offset shadows
- Oversized typography
- Monospace labels
- Strong contrast
- Asymmetrical layouts
- Editorial composition
- Visible grid structure
- Large numbers
- Technical labels
- Underlines
- Marquee text
- Overlapping elements
- Unexpected positioning
- Graphic color blocks
- Raw UI elements
- Intentional imperfections

The website should feel slightly unconventional while remaining highly usable.

==================================================
3D INTERACTION
==================================================

The 3D object should respond to mouse movement.

When the user moves the mouse:

Object rotates slightly toward the cursor.

Keep movement subtle.

Do not make it spin continuously.

Add gentle floating movement.

If the user drags the object:

Allow manual rotation.

Add inertia.

When the user stops dragging:

Slowly return to idle movement.

Add a tiny technical label near the object:

OBJECT / 001

DIGITAL ARTIFACT

MATERIAL / CHROME

ROTATION / 032°

These should use monospace typography.

Add a small:

label.

On mobile:

Disable drag interaction.

Use a gentle idle rotation.

If WebGL is unavailable:

Show a static high-quality fallback image.

==================================================
IMPORTANT DESIGN RULES
==================================================

1. Keep the brutalist identity consistent throughout the entire website.

2. Do NOT turn the website into a generic minimalist portfolio.

3. Do NOT use pill-shaped UI everywhere.

4. Do NOT use excessive rounded cards.

5. Do NOT use soft gradients.

6. Do NOT use glassmorphism.

7. Do NOT use pastel colors.

8. Use hard borders.

9. Use hard shadows.

10. Use oversized typography.

11. Use asymmetrical layouts.

12. Make the 3D hero object the visual signature.

13. The 3D object must support the typography, not overpower it.

14. Projects should feel like curated case studies, not generic cards.

15. Use animation sparingly.

16. Prioritize typography, composition, interaction, and visual hierarchy.

17. Every section should feel intentionally designed.

18. Avoid adding random decorative elements just because they are "brutalist."

19. Keep the website professional enough that a real client could hire the designer.

20. The first 3 seconds of the website should communicate:

"I am looking at a designer with a strong visual identity."
